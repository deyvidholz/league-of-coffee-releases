# League of Coffee for Windows

Installers for the League of Coffee desktop app: the League of Coffee site in a window, plus a
training overlay for League of Legends' Practice Tool.

**Download:** [LeagueOfCoffee-setup.exe](https://github.com/deyvidholz/league-of-coffee-releases/releases/latest/download/LeagueOfCoffee-setup.exe)
(always the latest version). Once installed, the app updates itself.

Windows may warn that the publisher is unknown the first time (the app isn't code-signed yet): click
**More info** → **Run anyway**.

This repository only holds the releases; the app's code lives elsewhere. Updates are signed, and the
app refuses any update that isn't.
